# StatTile

Grade de números da ficha: rótulo centralizado acima de um valor monoespaçado.

- Duas variantes: estatística (rótulo em MAIÚSCULAS, valor `stat` em negrito) e atributo (nome em negrito, valor, “MOD +N” em `secondary-color`).
- Valores sempre em `mono`; sinais explícitos (+2, -1).
- Grade fluida de colunas iguais com gap `space-2`; quebra sem rolagem horizontal.
