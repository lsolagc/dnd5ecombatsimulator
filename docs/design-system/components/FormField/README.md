# FormField

Campo com rótulo visível, controle do Bootstrap e texto de ajuda.

- Sempre `label` visível ligado ao campo; ajuda em `form-text` (`secondary-color`, .875rem).
- Valores de jogo (seed, dados, atributos) em `font-monospace`.
- Bordas `border-color`, raio `radius-control`; foco com borda `primary-border-subtle` e `focus-ring`.
- Selects usam `form-select`. Erros de validação vão num `Alert` acima do formulário, em frases (“Cada lado do combate precisa de pelo menos um personagem”).
