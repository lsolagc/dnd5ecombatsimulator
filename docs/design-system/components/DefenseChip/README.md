# DefenseChip

Seletor por tipo de dano que cicla — / R / I / V (resistência, imunidade, vulnerabilidade) a cada clique.

- O consumidor fornece o tipo de dano, o valor atual e o valor da ficha.
- Com valor: `is-active` (borda `body-color`, peso 600) e a letra em `mono`.
- Diferente da ficha: `is-edited` (borda `primary`, texto `primary-text-emphasis`).
- 13 tipos: ácido, frio, fogo, força, veneno, psíquico, radiante, trovejante, necrótico, perfurante, cortante, elétrico, concussão.
