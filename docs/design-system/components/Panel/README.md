# Panel

Contêiner base de seção: borda 1 px, raio `radius-panel`, fundo `body-bg`, padding `space-4`.

- Use para blocos de resultado, progresso, presets e estado vazio (`sim-empty-state`).
- Cartões dentro de um painel ficam em `tertiary-bg` com `radius-card`.
- Sem sombra, sem borda colorida — exceto o painel de lado (`SidePanel`).
