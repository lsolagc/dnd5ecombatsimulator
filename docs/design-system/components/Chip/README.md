# Chip

Pílulas de leitura: features da classe (com “nv N”) e tags de defesa no elenco.

- `feature-chip`: borda `border-color`, `radius-pill`, negrito; a variante esmaecida marca features que o personagem ainda não tem ou de outro arquétipo.
- `sim-tag`: defesa já resolvida no experimento — letra (R/I/V) + tipo de dano.
- Chips só leem; para alternar valores use `DefenseChip`.
