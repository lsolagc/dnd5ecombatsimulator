# WizardRail

Fluxo em etapas com trilho numerado à esquerda, cartão Resumo e rodapé de navegação.

- Passo ativo em fill `primary` com `on-primary`; passos não visitados em `secondary-color` e sem clique; visitados clicáveis.
- O Resumo (em `tertiary-bg`) se atualiza a cada campo.
- Rodapé: progresso em texto à esquerda, “← Voltar” (`btn-outline-secondary`) e “Continuar” (`btn-primary`).
