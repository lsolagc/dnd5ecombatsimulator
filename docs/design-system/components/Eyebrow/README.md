# Eyebrow

Sobretítulo curto em MAIÚSCULAS acima de um h1 ou do bloco de resultado.

- Estilo `eyebrow`: .75rem, peso 600, `letter-spacing` .12em, `secondary-color`.
- Variante de marca (só no hero da home) em terracota; use `primary-text-emphasis` para manter o contraste nos dois temas.
- Textos de status do experimento usam o eyebrow: “Na fila”, “Rodando”, “Resultado · N simulações”.
