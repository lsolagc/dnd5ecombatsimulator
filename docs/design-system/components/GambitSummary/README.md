# GambitSummary

Lista de leitura das regras de gambit, em ordem, como na ficha.

- Formato fixo: número em negrito, “Alvo: condição → ação”.
- Regras desligadas ficam esmaecidas e terminam com “(desligado)” — nunca só pela cor.
- Sem regra ligada, mostre “Ação aleatória” no lugar da lista.
- Em cartões de combatente e no elenco, acompanhe de um link “Editar gambits” para a tela do personagem; com 4+ combatentes por lado, colapse a lista.
