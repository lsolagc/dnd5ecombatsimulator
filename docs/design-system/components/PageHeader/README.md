# PageHeader

Cabeçalho de toda página: eyebrow opcional, h1, uma linha de subtítulo e as ações à direita.

- O consumidor fornece: título (`page-title`), subtítulo em `secondary-color` (contagem, “Guerreiro · nível 4”, seed), eyebrow (`sim-eyebrow`, MAIÚSCULAS) quando a página é um item de uma coleção, e até três botões.
- No máximo um `btn-primary` (a ação da página: “Novo personagem”, “Nova classe”); navegação em `btn-outline-secondary`; destrutivas (`Excluir`) em `btn-danger` por último.
- No mobile as ações quebram para baixo do título.
