# Button

Botões do Bootstrap 5.3 com a terracota como `primary`.

- `btn-primary`: a ação principal da tela, uma só (“Iniciar experimento”, “Novo personagem”, “Baixar logs”). Fundo `primary`, texto `on-primary`, hover `primary-hover`.
- `btn-outline-secondary`: navegação e secundárias (“Voltar…”, “Repetir com ajustes”, “Editar”).
- `btn-outline-danger`: destrutiva reversível ou interrupção (“Interromper”, “Remover”); `btn-danger`: exclusão (“Excluir”).
- `btn-outline-primary` existe na ficha (“Gambits”); no tema escuro o texto fica em 3,2:1 — prefira `btn-outline-secondary` em telas novas.
- Rótulo em verbo + objeto, caixa de frase. Foco: `focus-ring`.
