# Roster

Elenco gravado de um lado na tela Experimento: nome, classe · nível, linha de combate, defesas e gambits da cópia.

- Linha de combate em `stat-line` (`mono`): “HP 40/40 · CA 18 · +6 · 2d6 cortante”.
- Defesas como `sim-tag`. Gambits: modo “Gambits” ou “Aleatório”; a lista em ordem (`GambitSummary`) fica colapsada por padrão quando o lado tem 4+ combatentes.
- Borda esquerda de 3 px na cor do lado.
