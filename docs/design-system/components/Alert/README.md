# Alert

Mensagem de erro ou aviso em largura total, acima do conteúdo que ela afeta.

- Erro (`alert-danger`): validação e “falhou”. Fundo `danger-bg-subtle`, borda `danger-border-subtle`, texto `danger-text-emphasis`. Título em negrito + lista de motivos.
- Aviso (`alert-warning`): experimento interrompido (“considera apenas as N finalizadas”). Trio `warning-*`.
- Uma frase, sem ponto de exclamação; diga o que aconteceu e, se houver, o que fazer.
