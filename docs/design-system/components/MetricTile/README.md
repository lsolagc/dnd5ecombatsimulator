# MetricTile

Tile de uma métrica agregada do experimento: rótulo, valor grande e uma linha explicando o que o número mede.

- Exatamente as quatro métricas que existem: cura realizada, cura desperdiçada, maior dano em um round, tempo médio. Não invente outras.
- Valor em `tile-value`; dica em `meta` / `secondary-color`.
- Grade fluida (mín. 13rem), gap `space-3`; raio `radius-panel`.
