# DataTable

Tabela de coleção (Personagens, Classes) com filtros em linha e linhas expansíveis.

- Cabeçalho em MAIÚSCULAS negrito; nome em negrito; valores de jogo (`d8`, HP, CA) em `mono`.
- Linhas separadas só por `border-hairline`; detalhe expandido em `tertiary-bg`.
- Ações por linha à direita: Ver / Editar (`btn-sm btn-outline-secondary`), Excluir (`btn-sm btn-danger`).
- Filtros acima: busca, selects e “Filtrar” (`btn-outline-secondary`).
