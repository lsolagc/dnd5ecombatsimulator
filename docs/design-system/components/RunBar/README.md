# RunBar

Barra de execução de Novo experimento: quantidade, seed, resumo vivo e o botão principal.

- Quantidade de 1 a 1000; com seed preenchida a quantidade trava em 1 e o texto de ajuda explica.
- Resumo vivo em `secondary-color`: “2 contra 1 · 100 simulações”, ou o motivo do bloqueio (“Os dois lados precisam de pelo menos um combatente”).
- Desktop: fixa no rodapé (`position: sticky`, borda superior). Mobile: rola com a página e o botão ocupa a largura toda.
- É o único `btn-primary` da tela; fica afastado dos cartões do Lado B.
